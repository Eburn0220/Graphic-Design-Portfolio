# Emmanuel Burnett — Graphic Design Portfolio

Open `index.html` to view the gallery and printable résumé. The two AI-assisted Ex Libris presentation images are the gallery’s source images. The four PDF decks are web copies of Emmanuel’s project presentations.

To publish, use **Settings → Pages → Deploy from a branch → main → / (root)**. The live Pages URL is the link to share on LinkedIn. No build step is required.
